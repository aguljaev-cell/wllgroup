# Memory AI — desktop assistant

Локальный настольный AI-ассистент с постоянной памятью.

## Возможности
- Чат с AI через любой OpenAI-compatible API.
- По умолчанию готов для Ollama: `http://127.0.0.1:11434/v1`.
- История сообщений сохраняется локально в SQLite и не исчезает после перезапуска.
- Поиск релевантных прошлых сообщений автоматически добавляется в контекст ответа.
- Настройки URL, API key и модели сохраняются локально.
- Кнопка очистки полностью удаляет локальную историю.

## Запуск

1. Установить Python 3.10+ с Tkinter.
2. Если используете Ollama, установите Ollama и скачайте модель, например `llama3.2`.
3. Запустить:

```bash
python app.py
```

Для OpenAI-compatible сервиса откройте **Настройки** и укажите URL, API key и модель.

## Где хранится память

`~/.memory_ai/memory.db`

Это намеренно локальное хранилище. Репозиторий не содержит ваши API-ключи или историю.
