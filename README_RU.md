# PDFMathTranslate WLL v0.3

Windows-приложение для технического перевода PDF и DOCX на русский язык.

## Что входит в установщик

- графический интерфейс;
- Python-runtime и библиотеки приложения;
- локальный движок llama.cpp;
- обработка PDF и DOCX;
- загрузчик языковой модели с возобновлением загрузки.

Отдельно устанавливать Python или Ollama не требуется. При первом запуске приложение предлагает скачать модель Qwen2.5 7B GGUF размером около 4,7 ГБ. После загрузки перевод выполняется локально.

## Как получить Setup.exe через GitHub

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки, включая скрытую папку `.github`.
3. Зафиксируйте файлы в ветке `main`.
4. Откройте вкладку **Actions**.
5. Выберите **Build Windows installer**.
6. Нажмите **Run workflow**.
7. После завершения откройте запуск и скачайте artifact `PDFMathTranslate_WLL_Windows_v0_3`.

Кнопка **Run workflow** появляется только после того, как файл `.github/workflows/build-windows.yml` находится в ветке по умолчанию. Первый запуск также начнётся автоматически после загрузки файлов в `main`.

## Текущие ограничения v0.3

- OCR для сканированных PDF ещё не добавлен;
- сложные PDF могут требовать дополнительной подгонки размеров текста;
- цифровая подпись установщика отсутствует, поэтому Windows SmartScreen может показать предупреждение «неизвестный издатель»;
- антивирусы могут настороженно относиться к новым неподписанным PyInstaller-сборкам. Исходный код и workflow открыты и позволяют воспроизвести сборку.
