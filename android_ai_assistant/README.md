# WorldLogicLine Assistant

Отдельный Android-проект AI-ассистента компании WorldLogicLine.

## Цели
- AI-чат
- долговременная локальная память
- поиск по памяти
- подключение AI API без хранения ключей в APK
- экспорт/резервное копирование памяти
- сборка APK через GitHub Actions

Этот проект отделён от существующего инструмента перевода текста.
